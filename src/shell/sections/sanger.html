Chromatogram

Opent een Sanger-sequentiebestand (.ab1) en toont de gegevens van de run en de sequentie; een FASTA of geplakte tekst kan ook.

Het ABIF-formaat volgens Applied Biosystems, "ABIF File Format Specification and Sample File Schema" (2009). De basecalls, piekposities en kwaliteitswaarden zijn die van de sequencer zelf (PBAS2, PLOC2, PCON2); LabKit bepaalt de basen niet opnieuw. Phred-kwaliteit volgens Ewing & Green, Genome Res 8:186–194 (1998).
